# 🔺 Триумвират (Triumvirate)

Логическая пошаговая стратегия для браузера: шашки с **тремя цветами** и иерархией «хищник-жертва» против ИИ.

Игрок и компьютер выставляют шашки трёх типов (α, ω, δ) на доске 8×8. Каждый цвет бьёт только один другой цвет, что превращает классические шашки в стратегию с чтением намерений противника.

**[🎮 Играть в демо](https://andreybond77.github.io/triumvirate/)** · **[📂 Исходный код](https://github.com/andreybond77/triumvirate)**

---

## ✨ Возможности

- **Три уровня сложности:**
  - 🟢 Лёгкая — ИИ ходит случайно, игрок видит расстановку противника.
  - 🟡 Средняя — ИИ выбирает ходы с максимальным числом совпадений, игрок не видит шашки противника.
  - 🔴 Сложная — ИИ использует **Minimax с alpha-beta отсечением** (глубина 3), у игрока таймер 10 секунд на ход.
- **Система «хищник-жертва»:** α бьёт δ, δ бьёт ω, ω бьёт α. Одинаковые цвета могут меняться местами.
- **Отмена хода** — до 3 раз за игру.
- **Адаптивный интерфейс** — Canvas масштабируется под экран, поддержка мобильных устройств.
- **Звук и вибрация** — Web Audio API (синтез, без внешних файлов) и Haptic Feedback.
- **PWA** — Service Worker для офлайн-режима, манифест для установки.
- **Интеграция с Yandex Games SDK** — Game Ready, Gameplay API, реклама, сохранения (с fallback для локального запуска).

## 🛠 Технологии

| Слой | Что использовано |
|------|------------------|
| Рендеринг | HTML5 Canvas 2D (доска, шашки, анимации) |
| Логика | Чистый JavaScript (ES6+), без фреймворков |
| ИИ | Minimax + alpha-beta pruning, эвристическая оценка позиции |
| Звук | Web Audio API (осцилляторы, синтез тонов) |
| Стили | CSS3 (Grid, Flexbox, clamp() для адаптивных размеров) |
| PWA | Service Worker, Web App Manifest |
| SDK | Yandex Games SDK (с graceful fallback) |

**Без зависимостей.** Никаких npm-пакетов, сборщиков и фреймворков — только ванильный стек.

## 🚀 Запуск локально

### Вариант 1: Простой HTTP-сервер (рекомендуется)

Из-за Service Worker и модульной структуры игру нужно открывать через HTTP, а не `file://`.

```bash
# Python 3
python -m http.server 8080

# или Node.js (если установлен)
npx serve .

# или PHP
php -S localhost:8080
